🔍 Tình huống xử lý sự cố thực tế

Minh chứng cho tư duy logic và kỹ năng giải quyết vấn đề độc lập

Sự cố Mạng (Network)

Máy tính báo lỗi "No Internet Access" / Không vào được mạng

Hiện tượng: Máy kết nối Wi-Fi/dây LAN nhưng không tải được trang web hoặc báo lỗi DNS.
Cách xử lý: Kiểm tra trạng thái IP bằng `ipconfig /all`. Nếu nhận IP dải APIPA (169.254.x.x) $\rightarrow$ chạy `ipconfig /release` và `ipconfig /renew` để xin lại IP từ DHCP. Kiểm tra ping Default Gateway và 8.8.8.8. Nếu ping IP được mà không duyệt web được $\rightarrow$ gán lại DNS 8.8.8.8 / 1.1.1.1 và chạy `ipconfig /flushdns`.
Sự cố Phần mềm & Email

Outlook không gửi/nhận thư hoặc Google Workspace bị lỗi xác thực

Hiện tượng: Outlook báo lỗi "Disconnected", liên tục yêu cầu nhập mật khẩu hoặc hộp thư bị đầy.
Cách xử lý: Kiểm tra kết nối mạng và tình trạng tài khoản trên cổng Webmail. Xóa thông tin đăng nhập cũ trong Windows Credential Manager. Khởi động Outlook ở chế độ Safe Mode (`outlook.exe /safe`) để kiểm tra xung đột Add-in. Nén file dữ liệu `.ost/.pst` hoặc tạo mới Outlook Profile để tái đồng bộ.
Sự cố Phần cứng & Hệ thống

Máy tính bị treo đơ, màn hình xanh (BSOD) hoặc khởi động chậm

Hiện tượng: Máy tính khởi động không lên Windows, xuất hiện mã lỗi BSOD hoặc quạt quay mạnh kèm tiếng bíp.
Cách xử lý: Đọc mã lỗi (Stop Code) và phân tích file Minidump. Vệ sinh và gắn lại chân RAM. Kiểm tra tình trạng sức khỏe ổ cứng (CrystalDiskInfo). Sử dụng công cụ lệnh `sfc /scannow` và `DISM` để sửa file hệ thống hỏng. Nếu ổ cứng lỗi $\rightarrow$ tư vấn thay thế SSD mới và cài đặt lại bản quyền hệ điều hành.
